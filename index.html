Notes

Target color values must be integers from 0 to 16.

Input rows do not need to be sorted by x. They will be sorted automatically.

Duplicate x values are not allowed.

The "Add next x" button adds a row whose x value is one greater than the last row.
The "All Clear" button removes all input rows.

The Stop button immediately cancels the active scan. There is no resume function.

Attribution is optional, but I would appreciate it if you include a link to this page in your submitted code.

Update History

September 16, 2026: Added bottom-up symbolic regression.
Added separate controls for the expression-family scan and symbolic regression, including a configurable symbolic-regression state limit.
Reorganized Advanced options into common and search-method-specific settings.

September 2, 2026: Updated numeric literal generation and Lua numeric semantics.
Added configurable maximum results and decimal/hex fraction digit limits.
Moved scan settings into Advanced options and changed the scanner to display results immediately as they are found.
Added (a+x)^b and (a-x)^b with additional pruning.

August 22, 2026: Added a+x, x%a, a%x, f(x/a), f(x*a), f(x)/a, f(x)*a, where f is sin, cos, or tan.

July 29, 2026: Added Quick/Broad scan modes and the "All Clear" button.
Moved the scan to a Web Worker so that the Stop button can immediately cancel heavy computation.
Added x^a and some bitwise expressions.
Significantly improved scanning speed for a^x%b and x/a%b.

July 9, 2026: Added x/a, f(x/a)/b, f(x/a)*b, f(x*a)/b, and f(x*a)*b, where f is sin, cos, or tan.

June 28, 2026: Added a^x%b and x/a%b to the scanning expressions.
Significantly improved scanning speed.
Added the "Copy" button.

June 19, 2026: Released the first version.
