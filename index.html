Notes

Target color values must be integers from 0 to 16.

Input rows do not need to be sorted by x. They will be sorted automatically.

Duplicate x values are not allowed.

The "Add next x" button adds a row whose x value is one greater than the last row.
The "All Clear" button removes all input rows.

The Stop button immediately cancels the active scan. There is no resume function.

Update History

September 2, 2026: Updated numeric literal generation and Lua numeric semantics.
Added configurable maximum results and decimal/hex fraction digit limits.

June 28, 2026: Added a^x%b and x/a%b to the scanning expressions.

June 19, 2026: Released the first version.
